# Homebrew tap of StSchwerdtfeger

## Mousiki Plus

Terminal music player and internet radio: https://github.com/StSchwerdtfeger/mousiki-plus

For Mac with arm64 CPU:
```bash
brew install --cask stschwerdtfeger/tap/mousiki-plus
```
Intel CPU:
```bash
brew install --cask stschwerdtfeger/tap/mousiki-plus-universal
```

Then start it with `mousiki` (or `lala`) in Terminal or iTerm2.
